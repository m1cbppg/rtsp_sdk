## 最关键发现

- 16 条垃圾轨迹不等于 16 个垃圾。按候选中心 20px 的诊断性空间聚类，共形成 5 个垃圾位置。
- 其中 Track 68/87/119/137/182/185/189/200/203/225/233/237 位于同一位置，是一个垃圾在遮挡后反复断轨的强信号。
- 非垃圾 Track 3/85/92/94/138/180/184/190/193/199/202/230 同样集中在手推车底边位置，是固定/临时设施边界反复触发。
- 当前 PoC 已证明先验差分能独立发现小垃圾；下一优先级应是地面坐标轨迹续接和 actor/context 遮挡，而不是继续全局提高差分阈值。

## 推荐下一步

1. 为同一地面坐标保留 anomaly memory，短时遮挡后重新出现时续接原 Track。
2. 将人员、车辆、手推车、摊位覆盖区域标记为 OCCLUDED；遮挡区域不产生地面结论，遮挡消失后再和 clean reference 比较。
3. 对手推车底边、墙脚、ROI 边界建立 context negative evidence；不要用全局面积阈值删除，因为垃圾和非垃圾的像素尺寸高度重叠。
4. VLM 只审核去重后的持久候选，输入 reference crop、current crop、context crop、bbox 和轨迹历史。
5. 下一轮采集至少覆盖无垃圾、单个 T01 类垃圾、瓶罐、塑料袋、人员经过、车辆/摊位遮挡和白天不同时段，并按“唯一物体/事件”评估，而非只按 Track 数评估。
