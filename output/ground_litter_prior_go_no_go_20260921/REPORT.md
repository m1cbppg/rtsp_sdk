## 3. paired baseline 歧义

- 全部 1536 条试验中 baseline_ambiguous=0，即注入位置在同帧未注入图上没有既有候选；本次命中不是基线噪声。

## 4. 持续候选与确认误报

- 负样本阶段（真实 Selector + 真实 prior adapter + 现有 V33 状态机）在 45 分钟内未跑完，按 60–90 分钟预算**主动停止**。
- 因此 `确认 environmental false positive/小时` **未测量**：既不记为达标，也不记为失败。
- 负样本阶段状态：`error` `AttributeError: 'types.SimpleNamespace' object has no attribute 'startup_suppress_seconds'`
- 未做人工视觉归类：没有完成的持续事件集合可归类。

## 5. Selector 损失

- v3：oracle 0.1276 → active 0.05208（损失 0.07552），output 0.0
- v4：oracle 0.08203 → active 0.06641（损失 0.01562），output 0.0

active 损失无法单独归因于 Selector：oracle 本身只有 0.128，信号在残差/阈值阶段就已经很弱；active 与 oracle 的差距约 0.075，是次级因素。

## 6. 预注册判定

- 判定：**NO_GO**
- 依据：oracle_hit_rate=0.128 < 0.5
- oracle_hit_rate=0.1276（GO 门槛 0.7，NO-GO 门槛 0.5）
- prior_output_hit_rate=0.0；output/oracle=0.0
- confirmed_fp_per_hour=None（未测量）

主要缺口（具体距离）：
- v3 的 12–24px 合并 oracle：97/576 = 0.1684（GO 需 ≥0.70，NO-GO 下限 0.50）
- v4 的 12–24px 合并 oracle：62/576 = 0.1076（GO 需 ≥0.70，NO-GO 下限 0.50）
- v3 16px：46/192 = 0.23958
- v3 24px：45/192 = 0.23438
- v3 的 16+24px 合并：91/384 = 0.237，仍低于 0.70
- 结构可分性只在亮/暗纸片且尺寸 ≥16px 时出现；彩色包装与半透明塑料片在 8–24px 全部为 0（0/48 每组）。
- 8px：v3 oracle 0.0052（1/192）、v4 oracle 0.0052（1/192），单独报告，不作为唯一否决条件。

## 7. 性能（旁路离线，非生产 FPS）

- 核心扫描：2040.826 s；单 (帧, Profile) 评估 P50=1.2166 s、P95=1.668 s（n=1536）
- 缓存：hits=0, misses=1536
- 总墙钟：2165.4 s（含负样本阶段被停止前的运行时间）
- **未运行主视频链路**，不能声称主识别流不卡顿；这里只是旁路离线值。

## 8. 局限

- 合成注入只测结构信号，不代表真实垃圾准确率
- 真实目标样本数量为 0；未做人工视觉审核的事件只能叫未审核候选
- 主视频链路未运行，性能数字只是旁路离线值
- 环境覆盖只有 4 个 PS（4 个时段），未覆盖夜间/强阴影/雨后反光；`environments_detectable_min` 这条门槛无法严格判定。
- 未做视觉归类（likely_litter / environmental_false_positive / ambiguous）：负样本阶段未跑完，且没有真实目标可归类。

## 9. 判定与下一步

**NO_GO**。即使给出正确参考（每帧按粗距离取最相关的参考），8–24px 合成小目标的结构信号也无法稳定区分为前景。按任务书决策规则：停止当前背景先验检测路线，保留垃圾模型主链，转向小目标模型微调、放大裁剪或专用异物分类器；不再恢复 v6 工厂修复。

补充观察（不影响判定）：亮/暗纸片在 16–24px 有 27–67% 的结构命中，说明高对比、非彩色、≥16px 这一子集仍有残差可分离性；若将来选择放大裁剪路线，可作为 ROI 内先验提议的窄口径输入，但需要独立实验重新验收。
