# 固定摄像头垃圾候选分类可行性验证

日期：2026-09-22  
当前判定：**候选级有信号，事件级 NO-GO；路线已停止**

## 1. 验证的问题

用户的假设是：五个摄像头长期观察固定区域，误报物体和环境具有规律，因此可以训练一个针对
这些现场的过滤器；摄像头轻微变动或重画 ROI 时，视觉模型仍应可复用，现场适配部分可以低成本
重校准。

本轮没有训练新的垃圾定位器。`turhancan_yolov8m_seg_trash.pt` 继续负责尽量多地产生垃圾候选，
实验只判断候选的 crop（目标局部）和 context（周边环境）能否把垃圾与固定设施、车辆、纹理等
非垃圾分开。

## 2. 数据与防泄漏

- 人工明确标签：189 张 `LITTER`、2,083 张 `NON_LITTER`；
- 排除：153 张 `UNCERTAIN`、35 张 `BOX_WRONG`；
- 训练：2026-09-18、09-19；
- 模型和阈值选择：2026-09-20；
- 最终只读测试：2026-09-21；
- crop/context 完全相同的哈希没有跨越训练、验证和测试分区；
- 肉眼明显垃圾口径：框短边至少 12 px。更小正例不进入业务召回分母，但所有负例都保留。

最终测试共有 18 个垃圾候选，其中 10 个达到肉眼明显口径；最终 ROI 内只有 5 个垃圾候选，
其中 2 个达到肉眼明显口径。因此最终 ROI 指标只能决定是否继续，不能批准生产。

## 3. 误报是否可以只靠记忆位置消除

不能。最终 ROI 内有 370 张已审核非垃圾：

- 同摄像头、位置接近且外观相似的重复样本只占 21.4%；
- 最大严格簇只有 5 张；
- Top-20 严格簇只覆盖 14.3%，Top-50 只覆盖 25.9%；
- 只看位置时 Top-20 可覆盖 53.2%，说明固定位置明显，但同一位置的外观变化很大。

结论是坐标记忆可作为辅助屏蔽，不能作为主分类器。摄像头移动后，坐标规则还会失效。

## 4. 两个冻结特征探针

### YOLO26s 特征

最佳方案也是“共享 crop+context 特征 + 每摄像头线性头”，但新日期肉眼明显垃圾只命中 8/10，
非垃圾削减 55.5%，判定 `LEVEL_A_NO_GO`。这解释了旧线上过滤头为什么仍会放行大量误报。

### ConvNeXt-Tiny 通用视觉特征

使用 torchvision 官方 ImageNet 预训练权重，骨干完全冻结，只训练每摄像头一个线性头。
模型与阈值只由 09-20 验证集选择，09-21 测试结果为：

| 指标 | 结果 |
| --- | ---: |
| 验证集肉眼明显垃圾召回 | 45/48 = 93.75% |
| 验证集非垃圾削减 | 65.86% |
| 新日期全区域肉眼明显垃圾召回 | 9/10 = 90.0% |
| 新日期全区域非垃圾削减 | 63.97% |
| 新日期最终 ROI 全部垃圾召回 | 5/5 = 100% |
| 新日期最终 ROI 肉眼明显垃圾召回 | 2/2 = 100% |
| 新日期最终 ROI 非垃圾削减 | 66.67% |

唯一漏掉的肉眼明显正例来自 01028，位于最终 ROI 外，是靠近电动车/车辆的瓶状垃圾。01022
已知白纸通过。该结果达到冻结的 Level A 继续条件，判定 `LEVEL_A_GO`。

## 5. 结果意味着什么

固定摄像头适配确实有价值，但起作用的是“共享视觉语义 + 每摄像头轻量校准”，不是永久记忆
坐标。ConvNeXt 的正向结果证明现有人工卡片里存在可学习信号，也证明无需先投入长时间 detector
训练就能筛掉这条路线是否值得继续。

结果仍未达到生产门槛：候选级非垃圾削减约 64%，目标是至少 80%；最终 ROI 测试正例过少；
测试卡片是候选生成器已经找到的样本，不能证明端到端没有漏检。

逐摄像头数据也不均衡。01027 的验证集只有 1 个正例，最终测试没有正例，因此它的高阈值和
100% 负例削减不能解释为该摄像头已经可用；只能把 01027 当负样本压力段。正式上线前，每路
摄像头都需要足够的独立正事件，或退回有充分数据支撑的共享阈值。

最终 ROI 中仍被 ConvNeXt 放行的 14 张非垃圾卡片主要是电动车/车体、桌椅和店铺物体、地面
反光/砖纹、局部人物以及画面叠字。部分应在真实链路中先被 actor filter 或 overlay exclusion
删除，所以卡片级 66.7% 可能低估完整链路，但必须通过视频回放验证，不能据此推算。

## 6. 下一道闸门

冻结 ConvNeXt 头随后接入严格 ROI + actor filter，并要求 3 秒内同位置至少 3 次命中才形成
事件。01027 的 60 秒负样本保持 0 事件；01022 的已知白纸被保留，但 299 秒内共形成 46 个
确认事件，其中只有 1 个与白纸锚点重合。分类 P95 为 477 ms。

回放没有应用 overlay exclusion，部分叠字候选在完整生产几何中可以直接排除，因此本结果不证明
所有上下文分类方案都不可行。它证明当前冻结特征、当前标签量和当前事件链距离生产要求仍很远。
用户决定不再为此路线投入微调，相关实验代码已删除，数据和失败证据保留。

生产环境未修改。
