# Qwen VLM 极小目标多帧复核

日期：2026-09-17；模型：`qwen3-vl-plus`；调用次数：1。

## 结论

同一件历史用户确认的 8 像素垃圾，取三个不同时间的普通像素放大裁剪一起审核，VLM 仍返回
`uncertain`：目标是“极小亮色块状物，边缘模糊”，无法确认是否接触地面或物体材质属性。

这说明多帧只能增强“该处持续存在一个目标”的证据，不能恢复摄像头没有采集到的语义细节。
因此不能用“VLM 必须判断为 litter”作为这类极小目标的显示门槛。

## 调用事实

- 三张图来自同一固定位置的三个时刻；未向模型发送用户确认结论、YOLO 分数或标签。
- 图像只是普通最近邻放大，没有生成、锐化或修复细节。
- 请求耗时 2.81 秒，输入 1268 tokens，其中图像 1070；输出 56 tokens；合计 1324。
- 返回 JSON 可解析，`finish_reason=stop`。这是一次定向诊断，不是准确率或 SLA 测试。

## 对“两摄像头各负责近端一半”的影响

该调整是正确方向，但有效条件是：原来在一台摄像头中只有 8 像素的远端垃圾，必须交给
另一台离它更近、能形成更多有效像素的摄像头。只缩小原摄像头 ROI 或把裁剪放大，并不会增加
物体真实细节。

两台摄像头应按清晰度划主责任区，交界处留少量重叠，并为每个物理位置指定唯一主摄像头。
正式阈值应按两台摄像头在实际 mux 输入上的像素尺寸分别设置，不能共用旧 ROI 和阈值。
