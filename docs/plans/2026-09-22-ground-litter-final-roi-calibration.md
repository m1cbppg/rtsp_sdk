# 五路摄像头最终垃圾识别 ROI 标定计划

日期：2026-09-22  
状态：执行中

## 目标

冻结五路摄像头真正参与垃圾识别的地面区域。此前四路 `*_audit_geometry.json` 的用途是
尽量多挖候选，故意包含道路、车辆和商铺设施，不能用于生产误报评估。

## 标定方法

1. 每路取一张 2560×1440 的清晰代表帧；固定机位的 ROI 几何与昼夜无关。
2. 本地页面按画面边界依次点击，可绘制任意凹多边形；至少 3 点。
3. 页面实时显示闭合填充、顶点编号、归一化坐标，并支持撤销、清空和重新编辑。
4. 保存时写入摄像头编号、原始分辨率、归一化点、保存时间和帧 SHA-256。
5. 五路完成后生成独立 `final_roi` 配置；旧的宽 ROI 保留并明确标记为候选挖掘用途，
   不覆盖历史文件。

## 后续实验顺序

最终误报实验必须按以下顺序处理：

```text
最终 ROI 裁剪
  -> 人/车等 actor overlap 过滤
  -> Turhancan 垃圾候选
  -> YOLO26s 分类证据
  -> 有界时序状态
```

先用已经下载过的 01022 白纸段和 01027 压力段重放。白纸必须仍在 ROI 内并得到保留；
只统计最终 ROI 内、actor 过滤后产生的恢复事件。通过短窗口才扩到完整 5 分钟。
