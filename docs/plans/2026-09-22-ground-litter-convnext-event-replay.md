# ConvNeXt 候选过滤器事件级可行性回放计划

日期：2026-09-22  
状态：已完成并判定 NO-GO；用户决定终止本路线，实验代码已移除  
边界：服务器隔离目录离线回放；不修改生产代码、配置、容器或活动流

## 1. 要回答的问题

候选卡片实验中，冻结的 ConvNeXt-Tiny 特征加每摄像头线性分类头在独立日期达到：肉眼明显
垃圾召回 9/10，非垃圾削减 64.0%。这个结果只能说明卡片可分，不能说明实时视频中的事件数可用。

本实验把同一个冻结分类头接回真实候选链，回答四个具体问题：

1. 01022 已知白纸是否仍能经过严格 ROI、人物过滤、分类和三次命中确认形成事件；
2. 原回放中的立牌、桌面和井盖是否不再形成事件；
3. 01027 的 60 秒负样本段是否仍保持零事件；
4. crop+context 双路特征在 RTX 3060 Ti 上的 P95 是否足以用于旁路 latest-wins 分析。

## 2. 冻结输入与分类口径

- 候选：`turhancan_yolov8m_seg_trash.pt` 全帧加 ROI tile，阈值与前次回放一致；
- 空间范围：用户最终确认的每摄像头多边形 ROI；
- 人物/车辆：先执行 YOLO26s actor overlap 过滤；
- 分类骨干：torchvision 官方 ImageNet `convnext_tiny`，不更新权重；
- 分类头：候选级 Level A 实验冻结的 `camera_specific_crop_context`；
- crop：候选长边的 1.8 倍，最小 32 px；
- context：候选长边的 4.0 倍，最小 32 px，并复现审核卡片上的红色候选框；
- 打分：crop 与 context embedding 分别 L2 归一化后拼接，使用对应摄像头的 mean/std、
  linear weight/bias 和冻结阈值。

分类头不得根据这两段回放重新选阈值。模型文件、录像、几何文件和输出均记录 SHA-256。

## 3. 事件口径

分类通过不直接显示。通过的候选必须在 3 秒 TTL 内在同一位置累计至少 3 次命中，才形成一次
`classifier_passed_3hit` 事件。事件持续期间只更新同一事件，不允许逐帧重复计数。

本轮不把分类拒绝的候选重新用“重复出现”恢复为垃圾。此前已经证明桌面、立牌、井盖也会稳定
重复，恢复拒绝候选会抵消语义分类器的作用。

## 4. 实施步骤

1. 为离线回放器增加 `convnext_tiny` 后端和冻结分类头校验；
2. 增加 crop/context 复现与每摄像头 head 打分的单元测试；
3. 增加统一三次命中事件模式，保留旧模式用于历史结果复现；
4. 在服务器隔离目录重新拉取冻结的 01022、01027 PS 文件并校验原 SHA-256；
5. 先跑 01027 60 秒快速失败检查，再跑 01022 完整录像；
6. 生成事件卡片，人工复核事件类别，汇总性能、事件数和已知白纸命中；
7. 删除临时 PS，核对生产容器启动时间和重启次数未变化。

## 5. 判定规则

这一轮是进入一次轻量微调前的筛查，必须同时满足：

- 01022 白纸形成确认事件；
- 01022 已知立牌、桌面和井盖均不形成事件；
- 01027 为 0 个确认事件；
- 分类 P95 不高于 150 ms/tick，或能明确证明 latest-wins 旁路在 2 FPS 下无积压；
- 不读取回放结果来修改分类阈值。

通过表示“值得进行一次受控微调或扩展独立样本验证”，不表示可部署生产。最终生产门槛仍需
五路新时段 Shadow：肉眼明显垃圾召回至少 90%，非垃圾候选削减至少 80%，人工确认误报不高于
2 事件/小时。

若白纸丢失或已知固定设施仍成批形成事件，则停止当前冻结特征路线；先分析失败样本，再决定是
补困难负样本做一次轻量微调，还是转向专用检测器。

## 6. 实测结果与停止决定

- 01027：121 tick、118 个候选全部被 actor filter 删除、0 个事件；
- 01022：599 tick、白纸锚点事件 1 个，白纸在 549 tick 中保持激活；
- 01022：总确认事件 46 个，除白纸锚点外还有 45 个位置事件；
- ConvNeXt 分类 P95 477 ms、P99 601 ms；Turhancan P95 295 ms；
- 固定 batch 已消除由动态 batch 形状造成的 7～9 秒首次运行停顿，但正常延迟仍不满足 150 ms。

事件卡显示大量画面叠字、店铺固定结构、地面纹理和行人附近候选。回放未应用 overlay exclusion，
因此 46 不能直接等同于生产误报数；但在现有证据下仍明显未达到进入生产或继续微调的门槛。
用户决定停止该路线。实验脚本和测试删除，原有 YOLO 回放脚本按服务器历史副本 SHA-256
`58152eeb86a22747b06e894adf3a2d2599c2fcdb1b386e3e4521cffd61b17bd4` 恢复。
